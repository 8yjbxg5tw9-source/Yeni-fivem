# 196RP — STAFF STRUKTURU, SƏLAHİYYƏT MATRİSİ və ƏL KİTABÇASI

> Staff könüllü və maaşsız işləyir; IC-yə müdaxilə qəti qadağandır.
> Bu sənəd staff-ın OOC idarəetmə qaydalarını müəyyən edir.

---

## 1. İyerarxiya

```
Founder
  └─ Head Admin
       └─ Senior Admin
            └─ Admin
                 └─ Moderator
                      └─ Helper
```

| Səviyyə | Əsas vəzifə |
|---------|-------------|
| **Founder** | Layihənin sahibi; son qərar |
| **Head Admin** | Staff komandasını idarə edir; ağır cəza təsdiqi |
| **Senior Admin** | Adminləri idarə edir; mürəkkəb hallar |
| **Admin** | Ban/kick/warn, report yoxlaması, hadisə idarəsi |
| **Moderator** | İlk report yoxlaması, icma nəzarəti |
| **Helper** | Yeni oyunçuya kömək, sual cavab |

> **Ombudsman** iyerarxiyanın xaricində, müstəqildir.

---

## 3. Staff Əl Kitabçası (əsas prinsiplər)

### 3.1 Neytrallıq
- Staff heç vaxt bir oyunçunun tərəfini tutmaz.
- Dost, tanış, düşmən fərqi yoxdur — hamıya eyni qayda tətbiq olunur.

### 3.2 IC müdaxilə qadağası
- Staff IC hadisələrə qarışmır; OOC səlahiyyətini IC üstünlük üçün istifadə edə bilməz.
- Staff öz IC personajına OOC üstünlük (pul, əşya, məlumat) verə bilməz.

### 3.3 Dost-tanış qaydaları
- Dost/tanışın pozuntusunu ört-basdır etmək = ağır staff pozuntusu.
- Münaqişəli işdə staff özünü prosesdən kənarlaşdırır (recusal).

### 3.4 Bağışlanmaz səhvlər (dərhal staff-dan çıxarılma)
- IC müdaxilə / özünə və ya dostuna üstünlük.
- Logları silmə / saxtalaşdırma.
- Oyunçu məlumatlarını (IP, şəxsi) sızdırma.
- Rüşvət qəbul etmə.
- Staff səlahiyyətini şəxsi məqsədlə sui-istifadə.

### 3.5 Könüllülük və maaş
- Staff könüllüdür, maaş almır (IC-yə müdaxiləsizlik prinsipini qoruyur).

---

## 4. Eskalasiya Matrisi

| Hal | Qərar verən |
|-----|-------------|
| Sadə report / yüngül pozuntu | Moderator / Admin |
| Mürəkkəb report / təkrar pozuntu | Admin / Senior Admin |
| Permaban tələb edən ağır hal | Senior Admin + Head Admin |
| CK (Character Kill) qərarı | Məhkəmə və/və ya admin kollegiumu |
| Staff pozuntusu | Head Admin / Founder + Ombudsman |
| Pul/əşya yaratma icazəsi | Head Admin + Founder (audit log ilə) |

---

## 5. Staff Performans Nəzarəti

- Hər staff-ın əməliyyatları loglanır.
- Aylıq performans yoxlaması: cavab müddəti, düzgün qərar nisbəti, oyunçu məmnuniyyəti.
- Ombudsman staff-ın ədalətliliyini ayrıca izləyir.

---

## 6. Staff Qəbul Prosesi

1. **Form** doldurulur (yaş, təcrübə, RP anlayışı, boş vaxt).
2. **Müsahibə** (Head Admin / Senior Admin tərəfindən).
3. **2 həftə sınaq** (məhdud səlahiyyətlə, nəzarət altında).
4. Sınaq uğurlu olarsa, daimi status.

> *Staff könüllü əsasda, sınaq müddəti ilə və daim nəzarət altında işləyir.*
