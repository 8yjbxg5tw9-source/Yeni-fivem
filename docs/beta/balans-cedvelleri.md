## 6. Balans iclası formatı (aylıq)

1. **Rəqəmləri oxu** — gəlir/sink/inflyasiya/cinayət statistikası.
2. **Anomaliyaları müəyyən et** — hansı mənbə həddindən artıq gəlirli?
3. **Qərar ver** — dəyərləri dəyiş (bu cədvəl yenilənir).
4. **Dəyişikliyi elan et** — changelog + icma.
