# 196RP — FEEDBACK → PRIORİTET LÖVHƏSİ (Roadmap Board)

> İcma rəylərinin işə çevrilməsi prosesi. Şəffaf və izlənilə bilən.

---

## 1. Rəy toplama kanalları

| Kanal | Növ | Sürət |
|-------|-----|-------|
| Discord `#icma-rey` | Ümumi rəy | Orta |
| Beta bug hesabatı | Bug | Sürətli |
| Aylıq balans iclası | Sistemik | Yavaş |
| Ticket | Fərdi problem | Sürətli |
| Anket (beta sonu) | Hərtərəfli | Dövri |

---

## 2. Prioritetlər (təsnifat)

| Prioritet | Tərif | Cavab müddəti |
|-----------|-------|---------------|
| **P0 — Kritik** | Crash, dupe, exploit, qayda pozuntusu böhranı | Dərhal (saatlar) |
| **P1 — Yüksək** | Əsas sistem sıradan çıxıb, balans ciddi pozulub | 24–48 saat |
| **P2 — Orta** | Funksiya çatışmazlığı, UX problemi | Növbəti patch |
| **P3 — Aşağı** | Kosmetik, "gözəl olar" təklifləri | Roadmap-ə |

---

## 3. Roadmap board (statuslar)

```
Fikir → Qiymətləndirilir → Təsdiqləndi → İnkişafda → Testdə → Canlıda
```

Hər fikir:
- Rəy sahibi
- Təsvir
- Prioritet (P0–P3)
- Status
- Hədəf versiya/patch

---

## 4. Patch cədvəli (sənin bölmə 34)

- **2 həftədə 1 patch** (sabit cədvəl).
- Changelog Discord `#patch-changelog` kanalında.
- Hər patch: bug-fix + təsdiqlənmiş P2-lər + balans düzəlişləri.

---

## 5. Şəffaflıq prinsipləri

- Roadmap board **ictimai** (icma görə bilir).
- Rəy qəbul edilsə də, edilməsə də sahibinə səbəb bildirilir.
- Aylıq hesabat: nə təsdiqləndi, nə icra edildi, nə gözləyir.

---

## 6. Feedback loop (tam dövriyyə)

```
Oyunçu rəyi
    ↓
Qiymətləndirmə (staff + developer)
    ↓
Prioritet təyini
    ↓
Roadmap-ə əlavə
    ↓
İnkişaf → Test → Canlı
    ↓
Changelog + rəy sahibinə bildiriş
```

> *Bu proses "icma rəyi → prioritet lövhəsi" tələbinin tam icrasıdır (bölmə 34).*
